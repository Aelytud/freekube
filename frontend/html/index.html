FAQ

How it works

Are these real game servers?

They are stateless Python HTTP simulations pretending to be Minecraft, Satisfactory, Valheim, or Terraria servers. Everything around them—Kubernetes Deployments, Services, TLS Routes, HPAs, RBAC, NetworkPolicies, Redis queues, and Postgres—is real OpenShift infrastructure.

What happens when Redis restarts or dies?

Redis runs without persistence on purpose. Active sessions are cleared, and the maintenance CronJob automatically detects stuck provisioning/deleting rows in Postgres and re-enqueues them.

How does per-server autoscaling work?

When HPA is enabled on a server, the worker creates an autoscaling/v2 HorizontalPodAutoscaler targeting 60% CPU utilization. Open the server console and click "Simulate CPU Load" to watch OpenShift scale the deployment up.

Can I try it without registering?

Yes. Click "Launch instant demo" to create a temporary isolated guest account with full access to 2 free server slots.
